## 🎭 What is this magical creation?

A tribute to **Courage the Cowardly Dog** (Cartoon Network 1999–2002) brought to life as a **self-aware, interactive meme** living entirely in your browser! 🎮

Courage has been re-animated with modern web magic to become:
- 🧠 **Self-aware** - He knows he's a meme and breaks the 4th wall
- 🗣️ **Voice Interactive** - Talk to him with real-time voice chat
- 📺 **News Junkie** - Fetches real news hourly (good news = happy, bad news = 😱 explosion!)
- 🌍 **Scene Hopper** - Multiple interactive environments with day/night cycles
- 🎬 **TV Host** - Streams classic Courage episodes and meme content
- 🏃 **Runner** - Watch him run across your screen in his signature style

## 🚀 Quick Start (Easy Peasy!)

### 📋 **Prerequisites**
- Node.js 16+ 
- A sense of humor and love for pink dogs

### 🎮 **Installation**
```bash
# Clone this magical repository
git clone https://github.com/vmbbz/run-courage-run.git

# Enter Courage's world
cd run-courage-run

# Install the magic spells
npm install

# Bring Courage to life!
npm run dev
```

### 🌟 **Visit Live**
Open your browser and navigate to `http://localhost:5173` to meet Courage!
